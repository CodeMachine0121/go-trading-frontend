# 策略庫 — Briefing（討論摘要）

> 這份是與 James 討論後的原始共識摘要，作為 `/clarify` 的輸入。
> 正式的需求共識文件是同資料夾的 `BRIEF.md`。

## 起心動念

後端已經做好「策略」這份資料（`../go-trading`，PR #7 已合併）：
一支策略記住名稱、指標算式、指標值種類、彙總刻度、計算根數，並提供完整的建立／讀取／修改／刪除。

前端這邊，指標計算頁目前每次都要從空白開始寫算式，寫完算完就沒了。
這個切片把後端那份資料接上畫面，讓使用者寫過的策略能被留下來、叫回來、改、丟掉。

**整個功能做在「指標計算」這個 tab 裡**，不另開頁面。

## 三塊功能

### 1. 讀取與修改
編輯區上方一個下拉選單列出所有策略。選了之後：
- 算式內容灌進程式碼編輯區
- 指標值種類、計算根數、彙總刻度一併帶入

使用者改完後按「儲存」，做 update。

### 2. 新增
一顆「另存為新策略」按鈕，點了跳 modal 只問名稱，確定就送到後端建立。

**不做「先取名再開發」那一步**——使用者已經在編輯器裡了，跳出去填表反而打斷。
順序是「先寫、要存時才取名」。

### 3. 列表
一個 modal 清單列出所有策略，每一列旁邊有「載入」與「刪除」。
載入就關掉 modal 並灌進編輯器，不換頁。

## 已定案的取捨

**策略的 `script` 存「外框＋內容的整段算式」，不是只存內容。**
好處是後端拿到就能跑，下一個後端切片零成本。
代價是前端載回來要反向剝掉外框——解法是**把剝除放進 `IndicatorScriptDomain`**，
與 `assemble()` 並排，於是「全前端唯一產生算式文字的地方」這條規則仍然成立，
外框改了兩邊在同一個檔案裡一起改。

剝除**不比對外框文字**，改為錨定結構（`func Calculate` 那一行到最後一個 `}`，中間退一層縮排），
這樣外框日後多一個 import，舊策略照樣載得回來。
**認不出外框時整段原樣交還**，不硬剝——寧可讓使用者看到多了外框，也不要靜靜把程式碼剪壞。

**彙總刻度現在就放選單**（五分鐘／十五分鐘／一小時／四小時／一天），存進策略，
但旁邊要標明「目前計算仍以五分鐘執行，下一版生效」——後端還沒讓它作用在指標計算上。
不放的話每一支存下的策略都悄悄是五分鐘，等後端接上後使用者得回頭一支一支改。

**列表用 modal 不用獨立頁面**，因為要求是整個功能留在指標計算 tab 裡，
換頁會讓編輯器裡寫到一半的內容要嘛丟失、要嘛得做狀態保存。

**「儲存」只有一顆**：有載入策略就更新那一支，沒有就開同一個取名 modal 走新增。少一個概念要記。

**驗證只驗前端確定知道的**（名稱不可空白）。
名稱長度上限 128 **不寫死**——沿用 `IndicatorCalculationRequestDomain` 的既定作法：
那是後端的規則，前端寫死只會在後端改設定時說謊，一律由後端拒絕、前端如實轉達。

**交易標的不存在策略身上**，所以載入一支策略不會動到目前選的交易標的。

## 開發約定

- 每個段落與整合各自 commit 一次。
- Commit message 用英文並遵循 Conventional Commits。
- Commit message 不得出現任何 SDD 代號。
- 工作流程：`/clarify` → `/prd` → `/architecture` → `/implement codefirst`
  → `/improve-codebase` → `/contract`，最後開 PR。

## 後端契約（已上線）

| Route | 成功 | 失敗 |
| :--- | :--- | :--- |
| `POST /strategies` | `201` + 策略 | `400` 內容不合法 · `409` 名稱已被使用 · `502` |
| `GET /strategies` | `200` + 陣列（空為 `[]`） | `502` |
| `GET /strategies/:id` | `200` + 策略 | `400` 識別碼不可用 · `404` · `502` |
| `PUT /strategies/:id` | `200` + 策略 | `400` · `404` · `409` · `502` |
| `DELETE /strategies/:id` | `204` | `400` · `404` · `502` |

策略的形狀：
`id`、`name`、`script`、`resultType`、`aggregationInterval`、`candleCount`、`createdAt`、`updatedAt`。

`resultType` 四選一 `float`／`floatList`／`bool`／`boolList`，未指定視為 `float`。
`aggregationInterval` 五選一 `5m`／`15m`／`1h`／`4h`／`1d`，未指定視為 `5m`。
`candleCount` 介於 1 與後端的單次查詢筆數上限之間。
