# Product Requirements Document (PRD)

**Status:** Finalized
**Version:** v1.0
**Owner:** James Hsueh
**Stakeholders:** 使用者本人

---

## 1. Background & Goal (Why & Goal)

- **Problem Statement:** 行情圖表縮放、拖動時會卡會跳：長度一變超過兩成半就整批重取並整批換掉、畫面被擺回系統算的位置；
  挑「自動」時縮放跨過某個長度，K 線還會換一種粗細；即時更新每一則都整張重畫，拖到一半會頓一下。
- **Expected Outcome:** 縮放與拖動跟手、放手停在原地；粗細只在看的人自己換時才變；
  拖到資料邊緣時在那一側接上一段、畫面不動；即時更新只動最後一根。行為與 TradingView 一致。
- **Out of Scope:** 後端沒有的粗細（三十分鐘、二小時、一週…）；記住上次挑的粗細；重播與多圖。

---

## 2. User Personas

- **Primary Role(s):** 看盤的人（專案作者本人）。
- **Usage Context:** 桌機上長時間看盤、頻繁縮放拖動；手機上偶爾用手指拖。

---

## 3. User Stories & Acceptance Criteria

### US-01 — 粗細由看的人挑 [priority: P0]
**As a** 看盤的人, **I want** 自己挑每根 K 線多粗、縮放時不會被換掉, **so that** 我看的永遠是同一種 K 線。

```gherkin
Scenario: 只有六種粗細、預設一小時
  When 打開行情圖表
  Then 粗細按鈕是一分鐘、五分鐘、十五分鐘、一小時、四小時、一天
  And 一小時亮著
  And 沒有「自動」

Scenario: 換一種粗細
  Given 每根一小時
  When 按四小時
  Then 圖換成每根四小時，四小時亮著

Scenario: 縮放不換粗細
  Given 每根五分鐘
  When 拉遠到看得到好幾天
  Then 仍然是每根五分鐘
```

### US-02 — 快捷區間換到合適的粗細 [priority: P0]
**As a** 看盤的人, **I want** 按一個長度時一併換到適合的粗細, **so that** 每個長度畫出來都看得清楚。

```gherkin
Scenario: 按一天
  Given 每根一小時
  When 按「一天」
  Then 看最近一天，每根五分鐘，五分鐘亮著

Scenario: 按一年
  Given 每根一分鐘
  When 按「一年」
  Then 看最近一年，每根一天

Scenario: 按過快捷區間之後自己換粗細
  Given 按過「一天」（每根五分鐘）
  When 按十五分鐘
  Then 每根十五分鐘，看的那一段不變
  And 沒有任何一個快捷區間亮著
```

### US-03 — 縮放與拖動不整批重取 [priority: P0]
**As a** 看盤的人, **I want** 縮放拖動只動畫面、資料快用完時才在那一側接上, **so that** 圖跟手、不會跳。

```gherkin
Scenario: 手上的夠畫就不去要
  Given 手上這批涵蓋的比畫面寬很多
  When 拉遠一點、拉近一點、左右拖一點並放手
  Then 沒有跟後端要任何東西
  And 粗細不變

Scenario: 拖到快沒資料時往左接上更早的一段
  Given 往左拖到看的最早那一刻離手上最早那一根不到半個畫面寬
  When 放手
  Then 左邊接上更早的一段
  And 看的那幾根還在原本的位置上

Scenario: 離最早那一根還遠時不去要
  Given 看的最早那一刻離手上最早那一根有一個畫面寬以上
  When 放手
  Then 沒有跟後端要任何東西

Scenario: 那一頭已經沒有更早的資料
  Given 上一次往左接上來的一段一根都沒有
  When 繼續往左拖並放手
  Then 不再去要

Scenario: 往右接上更晚的一段
  Given 跳去看過一段過去、手上最新那一根早於現在
  When 往右拖到看的最晚那一刻離手上最新那一根不到半個畫面寬
  Then 右邊接上更晚的一段

Scenario: 放手之後畫面停在原地
  Given 拖動或縮放之後
  When 放手
  Then 畫面停在放手的地方，沒有被加上右側留白或擺回去

Scenario: 一次接上的一段不超過後端答得出來的根數
  Given 每根一分鐘
  When 往左接上更早的一段
  Then 那一段至多九百根
```

### US-04 — 即時更新只動最後一根 [priority: P0]
**As a** 看盤的人, **I want** 即時更新不重畫整張圖, **so that** 拖動中也不會頓。

```gherkin
Scenario: 還在走的那一根變了
  Given 看得到最新那一根
  When 還在走的那一根價格變了
  Then 只有那一根被更新，其他 K 線沒有重畫，畫面位置不變

Scenario: 最新那一根收完
  Given 看得到最新那一根
  When 下一根開始
  Then 右邊多一根，其他 K 線沒有重畫

Scenario: 接上更早一段之後畫面不動
  Given 圖上已有一批 K 線
  When 左邊接上更早的一段
  Then 看的那幾根仍在原本的位置
```

### US-05 — 跳轉時才擺位置 [priority: P1]
**As a** 看盤的人, **I want** 只有在我要求跳過去時才擺位置, **so that** 我拖到哪就停在哪。

```gherkin
Scenario: 換標的、換粗細、按快捷區間、跳到最新時擺回最新那一根
  Given 往回拖到看一段過去
  When 換一檔
  Then 畫面擺回看得到最新那一根，右側留白
```

## 4. Business Flow & Logic

- **Core Business Rules:**
  - **粗細**：六種（1m、5m、15m、1h、4h、1d），預設 1h，沒有「自動」。換粗細＝整批換成那一種、畫面擺回最新那一根。
  - **一進畫面**：看最近一個月、每根一小時，「一個月」與「1時」亮著。
  - **快捷區間的粗細**：一小時／五小時／十小時→一分鐘；一天→五分鐘；五天→十五分鐘；一個月→一小時；三個月→四小時；六個月、一年→一天。
  - **整批取（換一批）**：沒有手上這批、換了標的、換了粗細、或看的那一段整個落在手上這批之外。取的範圍是看的那一段兩側各多半段，至多九百根（太多時保留較晚那一端）。
  - **接上一段**：看的最早那一刻比手上最早那一根晚不到半個畫面寬、且那一頭還沒到底時，在左邊接上更早的至多九百根；右邊同理（看的最晚那一刻離手上最新那一根不到半個畫面寬、且手上最新那一根早於現在）。接上的一段一根都沒有時，那一頭記為到底。
  - **擺位置**：只在一進畫面、換標的、換粗細、按快捷區間、跳到最新時照既有右側留白規則擺；拖動或縮放之後不擺。
  - **即時更新**：還在走的那一根更新那一根；收完時接一根；不重畫其他 K 線。
- **Edge Cases:**
  - 接上一段時又拖到別處：只採用最後一次的結果（既有「只採用最後一次」規則）。
  - 接上失敗（連不上、被拒絕）：照既有方式說明，手上這批照樣畫著。

---

## 5. UI/UX Design & Interaction

- 粗細按鈕六顆：「1分」「5分」「15分」「1時」「4時」「日」。
- 接上一段時不顯示「行情載入中」以外的任何東西；畫面不閃、不跳。

---

## 6. Non-Functional Requirements

- **Performance:** 即時更新一則只更新一根；縮放拖動時不送任何請求，除非到了接上一段的門檻。

---

## 7. Dependencies & Risks

- 後端單次至多一千根；有休市的市場同一段時間根數較少，所以一次以九百根為上限。
