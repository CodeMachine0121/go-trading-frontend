## 1. Background & Goal (Why & Goal)

- **Problem Statement:**
  四個體驗上的破口，每一個都讓畫面說了一句不是實話的話：
  1. 挑到從市集加入的策略腳本時，編輯區**還留著上一支的內容**，而且改得動——讀起來像「我正在改別人的那一支」。
  2. 按下去之後要等系統回話的時候，畫面**看不出在等**；人會再按一次，或以為它壞了。
  3. 「連線狀態」是一整個去處，說的卻只是側欄那顆燈在每一頁都已經說了的事。
  4. 打開操作台時，**先露出一片空白的操作台**，再被帶到登入畫面——看起來像門沒關好。

- **Expected Outcome:**
  1. 挑到我加入的策略腳本時，編輯區切成唯讀、換上那一支自己的種類與參數，並明說不能改；
     而且在這一頁上**照樣試跑得了、回測得了**。
  2. 使用者在等系統回話時，畫面頂端有一條進度條；背景自己在做的事不讓它出現。
  3. 去處從九個變成八個，進門後的第一站是 K 線圖表。
  4. 在知道「你是誰」之前，**唯一看得到的是登入畫面的載入動畫**；任何一刻都不會露出操作台的空殼。

- **Out of Scope:**
  - 看得到別人的算式；把別人的一支複製成自己的。
  - 唯讀狀態下調整這一次的參數值（一律用分享者給的預設值）。
  - 蓋住整個畫面的等待遮罩。
  - 把連線狀態那一頁的內容搬到別的地方。
  - 登入畫面本身的欄位、規則與措辭。
  - 系統那一側的任何改變。

---

## 2. User Personas

- **Primary Role(s):** 操作台的唯一使用者——同時是**寫策略腳本的人**與**逛市集的人**。
- **Usage Context:** 桌機瀏覽器與手機直立（寬 390）兩種寬度都要成立；
  打開操作台是一天好幾次的事，挑策略腳本是一天很多次的事。

## 3. User Stories & Acceptance Criteria

### US-01 — 我加入的策略腳本看得到、用得了、改不動 [priority: P0]

**As a** 逛市集的人，**I want** 挑到我加入的策略腳本時畫面明說它改不動、但照樣讓我用，
**so that** 我不會以為自己在改別人的東西，也不必換一頁才能跑它。

```gherkin
Scenario: 挑到我加入的那一支就進入唯讀
  Given 我加入了市集上的「均線交叉」
  When 我在策略腳本那一頁從選單挑它
  Then 編輯區是唯讀的
  And 編輯區上方寫著「這支策略腳本是從市集加入的，不是你的——可以拿來試跑、回測，但不能修改。」

Scenario: 唯讀時看得到它的種類與參數但改不動
  Given 「均線交叉」正在唯讀中，它的指標值種類是「一串數字」、有一個參數「週期」預設 20
  When 我讀指標值種類與參數
  Then 指標值種類顯示「一串數字」且挑不動
  And 參數那一顆顯示「參數 1」，打開後看得到「週期 20」但改不動

Scenario: 唯讀時算式不公開
  Given 「均線交叉」正在唯讀中
  When 我讀算式那一欄
  Then 那一欄寫著「這支策略腳本的算式不公開」
  And 那一欄裡沒有任何算式，也打不進任何字

Scenario: 唯讀時會改動它的動作一律按不下去
  Given 「均線交叉」正在唯讀中
  When 我讀儲存、另存、改名、分享與帶入範例內容
  Then 這五個動作都按不下去

Scenario: 唯讀時照樣試跑得了
  Given 「均線交叉」正在唯讀中
  When 我按試跑
  Then 畫面算出「均線交叉」的指標值

Scenario: 唯讀時照樣回測得了
  Given 「均線交叉」正在唯讀中
  When 我執行回測
  Then 回測的是「均線交叉」，並顯示它的成績

Scenario: 離開唯讀挑自己的一支不必確認
  Given 「均線交叉」正在唯讀中
  When 我挑自己的「RSI 背離」
  Then 沒有任何確認
  And 編輯區換成「RSI 背離」且改得動

Scenario: 離開唯讀開一份空白不必確認
  Given 「均線交叉」正在唯讀中
  When 我開一份新的空白策略腳本
  Then 沒有任何確認
  And 編輯區是一份改得動的空白

Scenario: 有尚未儲存的變更時先確認
  Given 自己的「RSI 背離」改了一半還沒存
  When 我挑我加入的「均線交叉」
  Then 畫面先問要不要丟掉尚未儲存的變更
  And 答應之後才進入「均線交叉」的唯讀

Scenario: 自己的一支一切照舊
  Given 自己的「RSI 背離」
  When 我挑它
  Then 編輯區改得動，儲存、另存、改名、分享都按得下去
  And 畫面上沒有唯讀的說明
```

### US-02 — 等待看得出來 [priority: P0]

**As a** 操作台的使用者，**I want** 在等系統回話時看得出畫面在等，
**so that** 我不會重按一次、也不會以為它壞了。

```gherkin
Scenario: 按了之後要等一會兒
  Given 系統要一會兒才回話
  When 我按「存回目前這一支」
  Then 畫面頂端出現一條進度條
  And 系統回話之後那條進度條收掉

Scenario: 同時在等兩件事
  Given 我同時在等兩件事
  When 第一件回來
  Then 進度條還在
  And 第二件回來之後進度條才收掉

Scenario: 一眨眼就回來的不閃
  Given 系統在 0.2 秒內就回話
  When 我按下一個要問系統的動作
  Then 進度條從頭到尾沒有出現

Scenario: 失敗時照樣收掉
  Given 系統回了失敗
  When 那一件回來
  Then 進度條收掉
  And 失敗的原因照舊顯示在原本的地方

Scenario: 即時更新不算
  Given K 線圖表開著、即時更新在跑
  When 我什麼都沒按
  Then 進度條不出現

Scenario: 助手作答中的回頭詢問不算
  Given 助手正在作答
  When 畫面每隔一段時間回頭詢問一次
  Then 進度條不出現

Scenario: 連線燈的定期檢查不算
  Given 側欄的連線燈在定期檢查
  When 它去問一次後端還活不活著
  Then 進度條不出現

Scenario: 換畫面時也走一次
  Given 我在 K 線圖表
  When 我換到策略機器人
  Then 換頁期間進度條走一次
```

### US-03 — 沒有「連線狀態」這個去處 [priority: P1]

**As a** 操作台的使用者，**I want** 去處裡只留真的要去的地方，**so that** 進門的第一站就是我每天看的那一頁。

```gherkin
Scenario: 寬螢幕的側欄
  Given 我在寬螢幕上
  When 我讀側欄
  Then 有八個去處，沒有「連線狀態」
  And 側欄的連線燈還在

Scenario: 窄螢幕的「更多」
  Given 我在窄螢幕上
  When 我打開「更多」
  Then 只有 K 線瀏覽、Marketplace、交易策略、設定四條

Scenario: 登入成功沒有原本想去的地方
  Given 我沒有原本想去的那一頁
  When 我登入成功
  Then 我到 K 線圖表

Scenario: 打開網址的根目錄
  Given 我已登入
  When 我打開操作台的根目錄
  Then 我到 K 線圖表
```

### US-04 — 門口只有登入畫面 [priority: P0]

**As a** 還沒登入的人，**I want** 一打開就只看到登入畫面，**so that** 我不會先看到一片空白的操作台再被帶走。

```gherkin
Scenario: 沒登入的人打開操作台
  Given 我沒登入
  When 我打開操作台
  Then 我先看到登入畫面的載入動畫
  And 接著登入表單可以輸入
  And 任何一刻都沒有看到操作台的側欄或任何一頁的內容

Scenario: 已登入的人打開某一頁
  Given 我已登入
  When 我打開策略腳本那一頁
  Then 我先看到登入畫面的載入動畫
  And 接著直接是策略腳本那一頁
  And 中間沒有出現一片空白的操作台

Scenario: 確認幾乎瞬間完成
  Given 我沒登入，而且確認幾乎瞬間就完成
  When 我打開操作台
  Then 載入動畫至少停留 0.6 秒才換成登入表單

Scenario: 連不上系統
  Given 系統連不上
  When 我打開操作台
  Then 載入動畫收掉，登入表單出現
  And 表單上說明連不上系統

Scenario: 還沒被放行
  Given 我已登入但還沒被放行
  When 我打開操作台
  Then 我直接到等待開通那一頁

Scenario: 重新整理一頁之後回到那一頁
  Given 我沒登入
  When 我重新整理 K 線圖表
  Then 我先看到登入畫面的載入，接著是登入表單
  And 登入成功後回到 K 線圖表
```

## 4. Business Flow & Logic

- **Core Business Rules:**
  - **唯讀的判定只看「它是不是我加入的」**：挑到我加入的就唯讀，挑到自己的或開空白就不唯讀。
    沒有第三種狀態。
  - **唯讀時跑的是那一支本身**：試跑與回測指名那一支，連同它自己的指標值種類與參數預設值；
    畫面上不帶任何算式。
  - **唯讀時不可能有尚未儲存的變更**：沒有任何一格改得動，所以離開唯讀不必確認。
    進入唯讀之前若有尚未儲存的變更，照既有規則先確認。
  - **使用者在等的**＝使用者的操作觸發、畫面在等回話的那一次詢問；
    **背景的**＝畫面自己定期做的（即時更新、連線燈的定期檢查、助手作答中的回頭詢問）。
    前者算進進度條，後者不算。
  - **進度條只有一條**：還有任何一件使用者在等的事沒回來，它就在。
  - **門口的順序**：先確認你是誰 → 再決定給你看哪一頁。確認完之前，唯一畫出來的是登入畫面的載入動畫。
  - **第一站**＝K 線圖表：登入成功而沒有原本想去的地方、已登入的人走到登入畫面或等待開通那一頁、
    打開網址的根目錄，都到這裡。

- **Edge Cases:**
  - 唯讀中那一支被分享者從市集收回：照既有規則，下次重新整理可用策略腳本時它消失；
    唯讀中的畫面在那之前照舊，試跑或回測時由系統回的原因說明。
  - 唯讀中試跑失敗：失敗的原因照舊顯示在執行結果那裡，不因唯讀而不同。
  - 等待中換到別的畫面：前一頁那幾件回來時照樣收掉進度條，不會卡住。
  - 門口確認時連不上系統：視同沒登入，給登入表單並說明連不上（照舊）。

## 5. UI/UX Design & Interaction

- **Prototype Link:** N/A（沿用既有元件與 token）
- **Key Interactions:**
  - **唯讀說明**用既有的提示樣式（資訊類），擺在策略腳本那一列面板內、選單的下方；
    取代以前那一句「看不到它的算式」的提示。
  - **唯讀的編輯區**：算式那一欄換成一行置中的說明「這支策略腳本的算式不公開」；
    指標值種類選單與參數那一顆照常顯示、呈停用；參數打開後是唯讀清單。
  - **進度條**：畫面最頂端一條細的強調色橫條，不佔版面高度、不蓋住內容、不擋點擊；
    等待超過 0.2 秒才出現。換頁時同一條走一次。
  - **門口的載入**：與登入畫面同一張卡片、同一個位置，卡片裡是品牌記號與一個轉動的載入記號，
    底下一行「正在確認登入狀態…」；確認完、且至少停留 0.6 秒後換成表單（或離開）。
  - 窄螢幕（寬 390）上四件事一律成立。

## 6. Non-Functional Requirements

- **Performance:** 門口的載入動畫最短 0.6 秒，最長等同確認所需的時間；進度條門檻 0.2 秒。
- **Security:** 沒登入的人在任何一刻都看不到操作台的任何畫面（包含空殼）。
  這仍然只是畫面上的門——系統那一側的把關照舊。
- **Compatibility:** 桌機與手機瀏覽器；兩種寬度。
- **Analytics / Tracking:** N/A

## 7. Dependencies & Risks

- **External Dependencies:** 系統那一側已經能「指名一支策略腳本」來試跑與回測，這一刀依賴它，不要求任何改動。
- **Known Risks:**
  - 門口的改法會讓整台操作台只在瀏覽器裡畫出來；它本來就只在瀏覽器裡用，因此不影響部署方式，
    但第一次打開時多一段載入的時間——正是那段載入動畫要承擔的。
  - 背景詢問若漏標成「使用者在等的」，進度條會永遠在跑；每一個背景來源都要逐一確認。
