## 1. Nouns & Concepts
*Records entities, value objects, attributes and their correspondence between code and real business.*

| Domain Term | Technical Name | User-Facing Label | Definition & Business Rules | Status |
| :--- | :--- | :--- | :--- | :--- |
| K 線 | `KCandle` | K 線 | 市場在一段固定時間內的價量摘要。一根固定涵蓋**五分鐘**，以「交易標的 + 起始時間」唯一辨識 | Confirmed |
| 交易標的 | `symbol` | 交易標的 | 這根 K 線所描述的市場，例如 BTCUSDT。查詢與計算都必須指定；**不得為空** | Confirmed |
| 起始時間 | `openTime` | 起始時間 | 一根 K 線所涵蓋的五分鐘從何時開始。必須落在**五分鐘刻度**上、**不得指向未來**，一律以世界標準時間表示 | Confirmed |
| 開盤價 | `open` | 開盤價 | 該五分鐘內第一筆成交的價格 | Confirmed |
| 最高價 | `high` | 最高價 | 該五分鐘內的最高成交價。**不得低於最低價** | Confirmed |
| 最低價 | `low` | 最低價 | 該五分鐘內的最低成交價 | Confirmed |
| 收盤價 | `close` | 收盤價 | 該五分鐘內最後一筆成交的價格 | Confirmed |
| 成交量 | `volume` | 成交量 | 該五分鐘內成交的標的數量 | Confirmed |
| 成交額 | `quoteVolume` | 成交額 | 該五分鐘內成交的計價金額 | Confirmed |
| 主動買入量 | `takerBuyBaseVolume` | 主動買入量 | 該五分鐘內主動買方成交的標的數量 | Confirmed |
| 主動買入額 | `takerBuyQuoteVolume` | 主動買入額 | 該五分鐘內主動買方成交的計價金額 | Confirmed |
| 漲跌 | `KCandleDomain.priceChange()` | 漲跌 | 收盤價減開盤價。**大於零為上漲、小於零為下跌、等於零為持平**；供畫面決定呈現語氣 | Confirmed |
| 查詢區間 | `KCandleQueryDto` | 查詢區間 | 一次查詢的交易標的與開始時間。開始時間**可精確到分鐘、不必對齊五分鐘刻度**；**結束一律是送出當下的目前時間，使用者不指定**，因此開始時間不得晚於目前時間 | Confirmed |
| 彙總刻度 | `AggregationIntervalVo` | 每根涵蓋 | 圖表上一根 K 線涵蓋多久。五選一：**五分鐘、十五分鐘、一小時、四小時、一天**；由顯示區間長度自動決定，使用者不直接指定。沿用後端同名詞彙 | Confirmed |
| 顯示區間 | `KCandleChartViewportDto` | 正在看的區間 | 圖表上目前看得到的那一段時間。使用者拉遠、拉近、左右移動就會改變它；它的長度決定彙總刻度 | Confirmed |
| 已取回區間 | `KCandleChartDto.coveredStartTime` / `coveredEndTime` | 已取回區間 | 手上這批彙總 K 線涵蓋的時段。顯示區間完全落在其中、且彙總刻度沒變時**不重新取** | Confirmed |
| 顯示時區 | `TimeZoneDto` | 時區 | 操作台上所有時間的顯示與輸入用的時區。頂欄選單挑一個，這台瀏覽器記住它；預設世界標準時間，看不懂的識別字一律退回它。**只影響說法，不影響資料**——後端收發一律世界標準時間 | Confirmed |
| 位移標籤 | `TimeZoneDto.offsetLabel` | 例如 `UTC+08:00` | 該時區在**目前**相對於世界標準時間的位移；隨日光節約時間改變，因此一律在某個瞬間算出來 | Confirmed |
| 快捷區間 | `KCandleChartRangePresetDto` | 快捷區間 | 一鍵把顯示區間換成某個長度的選擇：一天、五天、一個月、三個月、六個月、一年。一律以目前時間為結束 | Confirmed |
| 取回計畫 | `KCandleChartLoadPlanVo` | *(不呈現)* | 對照顯示區間與已取回區間之後得出的結論：這次要不要重新取，以及要取哪一段、用哪一種彙總刻度 | Confirmed |
| K 線圖表 | `KCandleChartDto` | K 線圖表 | 圖表這一次要畫的東西：交易標的、彙總刻度、已取回區間，以及該區間內的彙總 K 線 | Confirmed |
| 畫法 | `KCandleChart` 的 `drawing` | 畫法 | 同一批 K 線要怎麼畫：**蠟燭**（看得到開高低收）或**曲線**（只連收盤價）。**純呈現選擇**——不影響取哪一段、也不影響資料怎麼解讀，因此住在畫面而不在領域 | Confirmed |
| 可查交易標的 | `TradingSymbolDto` | 交易標的 | 後端認得的一個交易標的：**它已登錄的**，加上**實際有 K 線的**。凡是要讀行情的畫面，交易標的都從這份清單裡挑，不手打。沿用後端同名詞彙 | Confirmed |
| 指標算式 | `script` | 指標算式 | 送給後端執行的一整段計算式，由**算式外框**與**算式內容**組成。使用者只撰寫內容，外框由畫面依指標值種類備妥 | Confirmed |
| 算式內容 | `scriptBody` | 算式內容 | 使用者親手寫的那一段——真正在算的幾行。**去空白後不得為空**；前後多餘的空白行不影響算式成立 | Confirmed |
| 算式外框 | `IndicatorScriptFrameDto` | 算式外框 | 每段算式都一樣的那些行：套件宣告、匯入、進入點簽章與收尾。**畫面備妥、唯讀**，並隨指標值種類改變產出形狀；一併備妥常用的數學與排序運算，內容裡可直接使用 | Confirmed |
| 指標值種類 | `resultType` | 指標值種類 | 這次算式產出的值長什麼樣子，四選一：一個數字、一串數字、一個是非、一串是非。**預設為一個數字**；同一次計算裡所有指標共用同一種；決定算式外框的產出形狀 | Confirmed |
| 計算根數 | `candleCount` | 計算根數 | 一次計算要餵給算式的 K 線根數。**必須大於零且不超過單次查詢上限** | Confirmed |
| 指標結果 | `IndicatorCalculationResult` | 指標結果 | 一次計算的產出：一組「指標名稱 → 指標值」，外加這次的指標值種類。**不留存**，空集合也是合法結果 | Confirmed |
| 指標值 | `IndicatorValueVo` | 指標值 | 某個指標名稱算出來的值。依指標值種類可能是一個數字、一串數字、一個是非或一串是非；一串可以是空的一串。**是非一律以「是」／「否」呈現**，呈現文字由領域決定而非畫面 | Confirmed |
| 實際採用根數 | `usedCandleCount` | 實際採用根數 | 這次計算真正餵給算式的根數 | Confirmed |
| 後端連線狀態 | `BackendHealth` | 後端連線狀態 | 後端服務目前是否可用。介面所有功能都以它為前提 | Confirmed |

## 2. Actions & Processes
*Records business operations, function logic, and their corresponding business actions.*

| Business Action | Technical Method | Trigger | Business Impact | Notes |
| :--- | :--- | :--- | :--- | :--- |
| 查詢 K 線 | `KCandleApplication.searchKCandles` | 使用者指定交易標的與開始時間後送出 | 畫面列出「開始時間到送出當下」之間的 K 線，依起始時間**由新到舊**（最新那一根在最上面） | 區間內無資料呈現「查無 K 線」而非錯誤；未指定交易標的、開始時間晚於目前時間、區間過大一律不送出或呈現後端說明的原因 |
| 看 K 線圖表 | `KCandleChartApplication.loadKCandleChart` | 進入圖表畫面、切換快捷區間、改交易標的，或在圖上拉遠拉近／左右移動 | 圖表畫出該顯示區間的彙總 K 線，每根涵蓋多久由顯示區間長度自動決定 | 顯示區間仍落在已取回區間內且彙總刻度沒變時**不重新取**；未指定交易標的不取；區間內無資料呈現「查無 K 線」；被拒絕或連不上後端沿用既有的呈現方式 |
| 列出快捷區間 | `KCandleChartApplication.listRangePresets` | 進入圖表畫面 | 畫面列出可一鍵切換的幾個區間長度 | 清單固定，不隨資料改變 |
| 列出可查交易標的 | `TradingSymbolApplication.listTradingSymbols` | 進入任何一個要讀行情的畫面 | 交易標的欄位呈現為可挑的清單 | 原本帶的那一檔不在清單上就改選第一個；清單是空的則維持原樣並說明後端沒有任何交易標的；取不到清單時明確說明，不留一個空白的選單。**新增／修改 K 線的表單不受影響**，那裡仍然手打 |
| 新增 K 線 | `KCandleApplication.createKCandle` | 使用者填妥一根 K 線的資料後送出 | 建立該根 K 線；同交易標的同起始時間已存在時**覆蓋**舊的 | 起始時間不在五分鐘刻度、最高價低於最低價、任一數字為負一律拒絕並說明原因 |
| 修改 K 線 | `KCandleApplication.updateKCandle` | 使用者在既有 K 線上改動價量數字後送出 | 更新該根 K 線的價格與成交數字 | **不得更換交易標的與起始時間**，畫面上這兩欄唯讀 |
| 刪除 K 線 | `KCandleApplication.deleteKCandle` | 使用者指名一根 K 線並確認刪除 | 移除該根 K 線 | 需二次確認；刪除後列表不再出現該根 |
| 執行指標計算 | `IndicatorCalculationApplication.calculateIndicator` | 使用者提供交易標的、計算根數、指標值種類與算式內容後送出 | 畫面顯示這次算出的每個指標名稱與數值 | 結果不留存；可用根數不足、根數不合法、算式無法解讀或執行失敗，一律不呈現任何部分結果，只說明原因 |
| 檢查後端連線 | `BackendHealthApplication.checkBackendHealth` | 進入畫面時自動、或使用者按下重新檢查 | 顯示後端目前是否可用 | 連不上時明確告知後端未啟動，而不是顯示空白畫面 |

## 3. Ambiguities & Conflicts
*Records cases where the same technical term means different things in different modules, or multiple terms refer to the same concept.*

| Ambiguous Term | Meaning in Context A | Meaning in Context B | Resolution |
| :--- | :--- | :--- | :--- |
| 「時間」 | K 線的起始時間（必須對齊五分鐘刻度） | 查詢區間的開始時間（可精確到分鐘） | 兩者分開稱呼：**起始時間**與**查詢區間開始時間**，畫面上的輸入限制也不同 |
| 「時區」 | **顯示時區**：畫面用哪一個時區說時間 | **時間基準**：與後端往來一律世界標準時間 | 兩者分開稱呼。領域內的時間永遠是一個**瞬間**，時區只在進出畫面的那一層發生作用 |
| 「區間」 | 表格畫面上使用者填開始時間、查到目前時間的**查詢區間** | 圖表畫面上使用者拉出來的**顯示區間**，以及據此取回的**已取回區間** | 三者分開稱呼，不簡稱為「區間」：查詢區間是填的（只填開始），顯示區間是看的，已取回區間是手上有的 |
| 「量」 | 成交的**標的數量**（成交量、主動買入量） | 成交的**計價金額**（成交額、主動買入額） | 沿用後端：中文一律以「量」指數量、「額」指金額，不混用 |
| 「最新一根」 | 列表上時間最晚的那一根 | 指標計算時被排除的那一根 | 兩者是同一根。畫面上說明「計算一律排除最新一根，因為它涵蓋的五分鐘尚未走完」 |
| 「錯誤」 | 使用者填錯（可自行修正） | 後端連不上（使用者無法自行修正） | 兩者呈現方式分開：前者標在欄位旁，後者整塊告知並提供重試 |

## 4. External & Enum Mapping
*Records magic numbers/strings in code and their real business meaning.*

| Category | Code Value / Key | Domain Label | Description |
| :--- | :--- | :--- | :--- |
| K 線長度 | 五分鐘 | K 線涵蓋時長 | 目前所有 K 線固定為五分鐘一根 |
| 起始時間刻度 | `:00, :05, :10, … :55` | 五分鐘刻度 | 起始時間唯一合法的取值；畫面在送出前先擋 |
| 單次查詢上限 | `1000` | 單次查詢筆數上限 | 一次查詢最多回傳 1000 根，超過由後端拒絕並請縮小區間 |
| 看得清楚的根數上限 | `400` | 畫面上最多的根數 | 顯示區間內最多擺幾根還看得清楚。彙總刻度就是照這個數字挑出來的：取最細的、且不超過這個數字的那一種 |
| 兩側預取比例 | 顯示區間長度的各半段 | 兩側預取 | 取資料時往前後各多取半段，使用者小幅拖動時不必重新取。因此一次最多取 400 × 2 = 800 根，永遠在單次查詢上限之內 |
| 彙總刻度 | `5m`／`15m`／`1h`／`4h`／`1d` | 五分鐘／十五分鐘／一小時／四小時／一天 | 五種可選的彙總刻度，與後端同名 |
| 畫法 | `candlestick`（蠟燭）／`line`（曲線） | 蠟燭／曲線 | 兩種畫法；預設為蠟燭 |
| 價量下限 | `0` | 價量最小值 | 所有價格與成交數字皆不得為負數 |
| 計算排除範圍 | 最新一根 | 計算時排除的 K 線 | 每次指標計算一律排除最新一根 |
| 時間基準 | 世界標準時間（UTC） | 後端收發的時間 | 與後端往來的每一個時間一律以此表示，不因顯示時區改變 |
| 可選的顯示時區 | 世界標準時間、台北、東京、香港、新加坡、倫敦、紐約 | 時區選單 | 固定清單，第一個是預設；每一個都標出目前的位移 |
| 查詢區間的結束 | 送出當下的目前時間 | *(不呈現為欄位)* | 表格畫面的查詢一律查到送出當下，與圖表快捷區間「一律以目前時間為結束」一致 |
| 記住選擇的地方 | 這台瀏覽器（`localStorage`） | *(不呈現)* | 沒有帳號，因此時區的選擇只跟著這台瀏覽器走，不跨裝置 |
| 漲跌語氣 | `up` / `down` / `flat` | 漲跌語氣 | 由漲跌算出，供畫面決定顏色；**判斷屬於領域，不寫在畫面上** |
| 指標值種類 | `float`／`floatList`／`bool`／`boolList` | 一個數字／一串數字／一個是非／一串是非 | 四種可選的指標值形狀；未指定時為 `float`。後端以同名詞彙收下 |
| 是非的呈現 | `true` → 「是」、`false` → 「否」 | 是非值 | 指標值為是非時畫面上的文字；**轉換屬於領域**，畫面只負責顯示 |
| 交易標的範例 | `BTCUSDT`、`ETHUSDT` | 交易標的 | 目前僅作為範例，尚未定義名稱格式規則 |
| 交易標的的來源 | 後端 `GET /trading-symbols` | 可查交易標的清單 | 讀行情的畫面上，交易標的的選項一律來自後端；畫面不寫死任何標的名稱 |
| 讀與寫的交易標的 | 讀行情＝從清單挑；建資料＝手打 | — | 新增 K 線正是新的交易標的誕生的地方，只能從既有清單挑的話就永遠建不出第一根 |
| 後端健康狀態 | `Healthy` | 後端連線正常 | go-trading 的健康檢查在一切正常時回傳的狀態值；大小寫與前後空白由前端正規化後比對，空值視為 `unknown` |

## 維護原則

1. **只反映現況**——本文件不記錄變更歷史，詞彙不再使用就刪除該列。
2. **先進地圖，再進程式碼**——新增業務詞彙一律先寫進本文件，不得自創同義詞。
3. **後端優先**——與後端 `.sdd/UL-MAP.md` 重疊的詞彙以後端為準，本文件只補上介面專屬的部分。
